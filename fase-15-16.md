# Fase 15: Busca Inteligente e Fase 16: Transferências

## 1. Busca Inteligente (Smart Search)
- **UI**: Adicionar um campo de input na barra de filtros.
- **Lógica**: Filtrar a lista `_allTransactions` em tempo real conforme o usuário digita.
- **Alcance**: Busca por descrição e tags (simuladas com # no texto).

## 2. Transferências entre Contas
- **UI**: Novo tipo "Transferência" no formulário de transação.
- **Campo Dinâmico**: Ao selecionar transferência, mostrar o campo "Conta de Destino".
- **Lógica**: Criar duas entradas no banco (Saída da conta A, Entrada na conta B) vinculadas por um ID de transferência único.
- **Impacto**: Atualização simultânea dos saldos de ambas as contas.

## Arquivos Afetados:
- `dashboard.html`: Ajustes no formulário e barra de busca.
- `main.js`: Lógica de filtro e criação de transação dupla.
- `style.css`: Estilos para o campo de busca e conta destino.
